# and AJ paw-pads デザインモック集

## 目的
このリポジトリは、ハンドメイドのペット用品ブランド **and AJ paw-pads** の公式ホームページ候補を比較検討するための、10種類のデザインモックをまとめたものです。  
本番サイト完成前の検討用であり、販売機能・決済機能・会員機能は含みません。

## ローカルでの確認方法
1. このリポジトリをPCに配置
2. `mockups/index.html` をブラウザで開く
3. 一覧から各モックへ移動して比較

## GitHub Pages公開想定
- HTML/CSS/JSのみの静的構成です。
- ビルド不要で、そのままGitHub Pagesに公開できます。

## 本番化時の方針
- 10案から選ばれた **1案** をベースに統合・発展させます。
- その後、必要に応じてUI改善・コンテンツ最適化を実施します。
